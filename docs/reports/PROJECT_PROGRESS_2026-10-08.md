# Task-Guided Graph：项目进展与下一阶段计划

**报告日期：2026 年 10 月 8 日**  
**服务器状态核验时间：北京时间 17:09**

## 一、当前结论

项目已完成 v0.6.2 的端到端基线实验，表示构建、MNGM 学图、Graph-RL 与专利引用检索流程均已跑通。当前重点是解决输入证据过短、不同概念使用相同证据，以及概念表示高度相关的问题。

v0.6.3 正在运行同一批 2048 篇专利的长文本对照实验。长文本准备已完成，全部样本成功补充发明概要、权利要求和详细说明；GPU 表示构建已完成 **1024/2048，即 50%**。目前还没有本轮完整的表示诊断与图结果，不能据此认定概念特异性或下游性能已经改善。

## 二、研究目标与方法

目标是从专利文本学习可供下游任务使用的概念关系图，并检验任务反馈能否带来具有实际检索价值的图调整。

当前主线采用 PatentsView H04L 授权专利数据，800 个 CPC 派生概念节点，冻结的 Qwen3-Embedding-0.6B 编码器，以及 64 维共享投影。下游任务是审查员引用的先前专利检索，采用固定 64 候选池；它不是 CPC 分类，也不是全库检索。

每篇专利为每个概念独立选择原文证据，共同编码后形成概念矩阵：

\[
H_d[:,c] = W F(\mathrm{concept}_c,\mathrm{evidence}_{dc}).
\]

其中，`F` 是冻结编码器，`W` 是沿用上一轮的共享固定线性投影。当前实验通过补充输入改善证据选择，保持这一表示定义；没有加入 prototype 相减、残差、强度门控或投影后逐列归一化。

整体流程为：**专利文本 → 按概念选择证据 → 冻结概念矩阵 H → MNGM 概念图 → 下游检索与任务反馈**。本轮只执行前三项及学图，第二阶段任务训练保持暂停。

## 三、已完成工作与关键发现

### 1. v0.6.2 端到端基线已经完成

- 使用 2048 篇训练专利、800 个概念、64 维表示完成缓存构建。
- 完成 8 个 Graph-RL 阶段，共评估 192 个候选图；报告中的候选求解均收敛。
- 第 4、6、7 阶段接受图更新。
- 表示构建耗时约 **2.97 小时**，训练阶段约 **10.50 小时**。

验证集结果如下，均基于 64 候选池、256 个验证查询：

| 指标 | 初始状态 | 最终状态 |
|---|---:|---:|
| 平均 NLL，越低越好 | 4.0251 | 3.9251 |
| MRR，越高越好 | 0.1796 | 0.2340 |
| Recall@1 | 8.59% | 13.67% |
| Recall@10 | 35.94% | 41.41% |

最终测试集共有 1024 个查询，MRR 为 **0.2869**，Recall@10 为 **49.32%**。现有结果没有对应的初始测试集指标，因此不将其写成测试集提升量。

这些结果说明整体流程可执行，最终检索表现优于初始验证状态，但还不能把提升归因于图学习。阶段记录中，接受图更新对应的验证 NLL 改善合计约 **0.000857**，后续任务适配对应约 **0.099097**。这是阶段变化的记录，不是固定图、等训练预算的因果对照；下一阶段需要补足该对照。

### 2. 发现短输入限制了概念特异的证据选择

上一轮图学习输入主要是标题和摘要。对全部 2048 篇的审计发现：

| 诊断项 | v0.6.2 结果 |
|---|---:|
| 候选片段不超过 6 个的文档 | 1330 篇 |
| 所有概念选中同一组证据的文档 | 1332 篇，65.04% |
| 按文档平均的概念对证据相同比例 | 75.23% |
| 实际最长联合输入 | 509 tokens |

在候选片段不超过 6 个时，top-6 往往会选入全部片段，无法为不同概念提供不同的证据。上一轮没有发生联合输入截断，主要问题是候选证据不足。

初始图使用的有效概念协方差中，最大特征值占总迹约 **95.40%**，参与率有效秩约 **1.10**，说明概念轴存在很强的共同变化方向。证据共享是需要验证的解释之一，目前尚不能认定它是唯一原因。

## 四、当前长文本实验：设置与实际进度

### 1. 实验设置

| 项目 | 当前设置 |
|---|---|
| 样本 | 与 v0.6.2 完全相同的 2048 篇，保留 ID 和顺序 |
| 新增文本 | 同一专利的发明概要、权利要求、详细说明 |
| 数据快照 | PatentsView 2024-12-31 |
| 每篇候选文本上限 | 4096 个 Qwen tokens，包含原标题、摘要和章节标题 |
| 新增章节初始预算 | 概要 20%、权利要求 25%、详细说明 55%；不足部分重新分配 |
| 超预算文本 | 从原文不同位置保留片段，再恢复原文顺序 |
| 分片上限 | 128 tokens；实际片段可以更短 |
| 证据选择 | 每个概念独立选择 top-6 |
| 联合编码上限 | 1024 tokens |
| 编码 batch | 8 |
| 概念数 / 表示维度 | 800 / 64 |
| 概念图稀疏惩罚 λ | 全程固定 0.8，非对角边统一惩罚，对角线不惩罚 |
| 表示维度精度矩阵 B 的惩罚 | 固定 0.4 |
| 学图流程 | 先固定 B=I 求初始图，再进行固定 λ 的交替 MNGM 拟合 |
| 第二阶段 | 本轮不运行任务模型、LoRA 或 GRPO |

当前 λ=0.8 用于保持与上一轮初始图的可比性，尚未针对长文本重新调优。本轮不同时调整 λ 与输入，以便先观察输入扩展带来的变化。

### 2. 长文本准备已得到全量实测结果

2048 篇全部成功扩展，三类新增章节均覆盖全部样本。

| 文本部分 | 原文 token 中位数 | 原文 token 最大值 | 实际保留 token 均值 |
|---|---:|---:|---:|
| 发明概要 | 1484 | 13165 | 790.8 |
| 权利要求 | 1387.5 | 12971 | 899.9 |
| 详细说明 | 5446.5 | 142916 | 2167.8 |

原有标题和摘要平均 **163.7 tokens**；扩展后的完整候选池平均 **4031.2 tokens**，中位数 **4080**，最大 **4083**，均在 4096 的预算内。详细说明的极长原文只在准备阶段用于 token 计数和原文片段选取，没有原样送入 GPU 模型；进入联合编码的输入另受 1024-token 上限约束。

## 五、下一步计划

### 第一步：完成当前全量学图，并核验产物

等待全部表示缓存、初始图与固定 λ MNGM 图完成，检查缓存完整性、输入校验和、样本/概念顺序，以及求解的收敛、正定性和 KKT 检查。保留当前长文本预算与 λ 设置，不同时引入新的方法改动。

本轮将输出长度审计、证据多样性报告、表示余弦诊断、协方差谱、图矩阵、求解日志及自动报告包。

### 第二步：回答输入扩展是否解决了核心问题

与 v0.6.2 在完全相同的样本和概念上逐一比较：

1. 候选片段是否增加；不同概念是否开始选择不同证据。
2. 全概念共享证据的文档比例、概念对证据重合率、独立证据集数量如何变化。
3. 原生 Qwen 空间和投影空间中，表示与 prototype、空证据同模板表示的相似度如何变化。
4. 实际 MNGM 协方差的共同方向、有效秩和相关性是否改善。
5. 相同 λ、相同 B=I 初始条件下，图的边数、边集合和权重如何变化。

同时从全量结果抽取原文与概念的证据例子进行人工核对。证据更不同、余弦更低或图变化更大都不是单独的成功标准；需要确认选中的片段确实与相应概念有关。

旧缓存没有保存原生 Qwen 全维表示，因此旧、新表示的直接数值比较主要在相同投影空间进行；本轮原生空间诊断用于评估新表示与已有 prototype/空证据基线的关系。图结构变化也不能直接解释为图更正确或更稳定。

### 第三步：按诊断结果选择后续路线

- **若证据多样性与概念语义对应均改善，且求解稳定：**将本轮表示作为下一轮候选，另行启动第二阶段检索实验。
- **若证据多样化，但概念协方差仍高度集中：**进一步检查编码器共同方向、概念语义重叠及固定投影的影响，再决定是否需要表示方法改动。
- **若证据质量变差：**先调整章节分配或片段选择，保留原文核验，重新做可比的学图实验。

不以人为降低 prototype 余弦作为优化目标。当前第二阶段训练保持暂停，待本轮诊断审阅后再决定启动。

### 第四步：验证图对下游任务的独立贡献

后续检索实验应增加固定图对照，在相同初始任务模型/LoRA 权重、训练步数、查询流和候选池下比较初始图、学习图及适当的结构对照。将图变化与任务适配的影响分开，避免把额外训练预算带来的提升解释为图结构收益。

在输入方案确定后，再考虑 λ 敏感性分析、不同随机种子和更广年份覆盖。当前 2048 篇子集全部来自 **2005 年授权专利**，虽然保持了与旧实验的配对可比性，但不能代表整个 2005—2024 年语料的覆盖或泛化表现。
