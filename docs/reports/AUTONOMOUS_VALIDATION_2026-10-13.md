# Task-guided 图学习：自主验证阶段记录

更新时间：2026-10-13 19:27（北京时间）。这是阶段结果，定向图优化仍在运行。

目前尚未得到 task-guided 图优化或 GRPO 有效的证据。已确认求解速度和分类头
有明显改进空间；这些收益需要与图结构、策略学习的收益分别验证。

所有实验使用全部 4563 条训练记录、876 个具体概念、原有 8 个诊断标签。
验证集为 777 条；测试集未打开。以下都是探索性验证结果。

| 实验 | 验证 macro-AP | 验证 macro-F1 | 判断范围 |
|---|---:|---:|---|
| 原流程初始图 | 0.865017 | 0.673810 | checkpoint 重载完全复现 |
| 原流程 GRPO 最终图 | 0.864771 | 0.670855 | 本次 GRPO 未改善泛化 |
| 原任务冻结，训练集选择统一惩罚 λ=0.4 | 0.863326 | 0.672120 | 固定 B 的条件搜索未改善 |
| FP32/平均池化，固定图，seed11 | 0.870351 | 0.790198 | 图分支恢复健康；只有一个种子 |
| 同一对照的无边概念分支 | 0.866006 | 0.782006 | 图与无边差约 0.00434 AP，尚不足以证明有效 |
| 同一对照的文本分支 | 0.300728 | 0 | 训练异常，触发预设的停止扩种子规则 |

不能用异常文本对照证明图有用，也不能只挑成功分支当成三种子验证。
保持原结构、恢复初始化后随机状态的复现实验依然失败（AP 0.2084），所以
随机状态重置不是已证实的唯一原因。失败文本模型的表示在样本间几乎不变化。

复用已缓存的平均池化文本特征，冻结语言模型，对全部训练样本拟合新的 FP32
线性分类头。三个种子 11/17/23，300 步，学习率 0.01，仅用训练集归一化。
报告每个设置，不用验证集选择。± 为三个分类头种子的样本标准差，
不是独立语言模型训练的波动，也不是置信区间。

| 固定表示及损失 | 验证 macro-AP 均值 | 验证 macro-F1 均值 |
|---|---:|---:|
| 原成功 LoRA，普通 BCE | 0.901401 ± 0.000522 | 0.842946 |
| 原成功 LoRA，平方根正例加权 BCE | 0.903918 ± 0.000346 | 0.845750 |
| 未训练 LoRA 的基础模型，普通 BCE | 0.811026 ± 0.002511 | 0.687457 |
| 基础模型，平方根正例加权 BCE | 0.814242 ± 0.002144 | 0.757113 |

原 LoRA 的特征提取没有图前缀，但 LoRA 本身来自带图训练，0.9014 不能
称为独立训练的纯文本基线，也不能证明图无价值。它说明现有表示中有更强的
可读出信号，原分类头没有充分利用。后续图方法应面对更强、匹配的读出对照。
普通 BCE 训练 AP 均值约 0.9532，原训练来源和 data0 来源都学到了信号。
不能仅凭来源分布差异认定 data0 无效。患者标识缺失；未发现训练/验证的完全
相同文本，但无法确认按患者划分的独立性。

计算改进已经验证：真实 876 概念问题上，对偶热启动修复让原问题重复求解由
864.26 秒降至 0.19 秒；对惩罚改变 5% 的问题，只由 748.03 降至 738.65 秒。
固定 ADMM 参数 ρ=10 后，同一个改变惩罚的子问题需 73.22 秒、587 次迭代，
相对原 ρ=1 的 748.03 秒约快 10 倍。正定、残差和 KKT 要求不变，目标函数
一致。这是求解子问题速度，尚不是完整交替 MNGM 的实测加速。

完整 4563×64×876 规模的双精度 GPU 测试：概念协方差由 2.61 秒降至 1.49 秒，
表示协方差由 3.49 秒降至 0.81 秒，统计损失由 2.22 秒降至 0.91 秒，
与 NumPy 结果的相对差约 2×10⁻¹⁵。这些计算只占几秒，总体瓶颈仍是统计
求解和重复大模型评估。缓存特征后，本次线性头 300 步仅约 1.4 秒。

已启动 seed11 定向图优化：冻结健康的图任务 checkpoint，全部训练记录上
计算排序代理损失对精度矩阵的梯度，通过经数值扰动检查的条件 Glasso 隐式
导数映射到惩罚。比较三个定向步长、三个相同取值分布的置换方向、三个统一惩罚。
各家族都保留初始图，只根据训练 macro-AP 选择，限制似然恶化和图复杂度。
选出的惩罚再做完整交替 MNGM，重新检查约束和训练收益。

这是梯度优化对照，不是 GRPO，也不是统计置信度方案。行动范围暂用初始偏相关
绝对值至少 0.001 的边，是经验拟合支持，不能冒充置信区间或错误发现控制。
同预算比较首先指候选数量；定向方法另需梯度，最终还应比较总耗时。

原定目标为最强匹配对照的平均 macro-AP 至少增加 0.005、macro-F1 不下降
超过 0.002，并有跨种子的方向一致性。只改善读出、训练奖励或单个种子，
不能宣布达标。正式测试确认前还需锁定方案。GRPO 独立收益和不同初始图迁移
仍另行验证。

代码、协议和实验入口：[GitHub 草稿 PR #4](https://github.com/ZZzzecho/task-guided-graph/pull/4)。
没有合并；临床文本、关键词内容、权重、缓存和逐样本预测留在私有服务器。
